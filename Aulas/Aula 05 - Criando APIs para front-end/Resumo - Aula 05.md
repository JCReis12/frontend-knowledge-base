# Resumo da Aula 05: Criando APIs para o Front-end

## Conceitos fundamentais

### API

Uma API permite que diferentes sistemas se comuniquem por meio de requisições.

### Endpoint

É o caminho de acesso usado para realizar uma requisição a uma API.

### JSON

Formato de texto usado para representar e trocar dados entre sistemas.

## Métodos HTTP

| Método | Operação |
| --- | --- |
| `GET` | Busca dados. |
| `POST` | Envia dados, geralmente para criar um registro. |
| `PUT` | Atualiza um registro por completo. |
| `PATCH` | Atualiza parcialmente um registro. |
| `DELETE` | Exclui um registro. |

## CRUD

CRUD reúne as operações básicas de criação, leitura, atualização e exclusão de dados:

- **Create (criar):** adicionar um registro.
- **Read (ler):** consultar registros.
- **Update (atualizar):** alterar um registro.
- **Delete (excluir):** remover um registro.

### Exemplo: sistema de bloco de notas

- Listar todas as notas.
- Consultar uma nota específica.
- Criar uma nota.
- Atualizar uma nota.
- Apagar uma nota.

## Ferramentas e publicação

- **Postman:** testar requisições e endpoints da API.
- **Repositórios:** organizar o código do front-end e do back-end.
- **Vercel e Render:** plataformas mencionadas para publicação de projetos.
