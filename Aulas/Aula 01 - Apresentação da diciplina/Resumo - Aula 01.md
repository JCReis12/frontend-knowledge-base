# Aula 01 – Apresentação da Disciplina e Contextualização

## Objetivo da Aula

A primeira aula teve como objetivo apresentar a disciplina de **Frameworks Front-end**, sua importância no mercado, o plano de ensino, a metodologia adotada durante o semestre, os critérios de avaliação e os principais conteúdos que serão estudados.

---

# Apresentação da Disciplina

A disciplina tem como foco o desenvolvimento de aplicações Web modernas utilizando Frameworks Front-end. Durante o semestre serão abordados conceitos fundamentais, ferramentas e boas práticas utilizadas no desenvolvimento de interfaces profissionais.

Também foram apresentados:

- Objetivos de aprendizagem;
- Ementa da disciplina;
- Conteúdo programático;
- Metodologia de ensino;
- Recursos didáticos;
- Critérios de avaliação;
- Bibliografia.

---

# Contexto da Disciplina

O uso de Frameworks Front-end tornou-se um requisito estratégico para empresas que desejam desenvolver aplicações modernas, organizadas e de fácil manutenção.

A arquitetura de software permite organizar melhor os componentes da aplicação, facilitando sua evolução e manutenção.

Atualmente, grande parte das aplicações Web utiliza algum Framework Front-end devido aos benefícios de produtividade, reutilização de código e melhor experiência para o usuário.

---

# O que é Desenvolvimento Front-end

O Front-end corresponde à camada da aplicação com a qual o usuário interage diretamente.

Suas principais responsabilidades são:

- Construção das interfaces;
- Organização visual dos elementos;
- Experiência do usuário (UX);
- Comunicação com os sistemas responsáveis pelo processamento dos dados.

---

# Arquitetura de um Site

Antes do desenvolvimento de uma aplicação é importante definir:

- Escopo do projeto;
- Prototipação;
- Experiência do usuário (UX);
- Interface do usuário (UI);
- Validação de ideias;
- Refinamento da usabilidade;
- Iteração durante o desenvolvimento.

Também é incentivada a utilização de ferramentas de prototipação para auxiliar na criação dos projetos.

---

# Versionamento e Deploy

A disciplina introduz os conceitos de:

- Versionamento de código;
- Utilização do Git e GitHub;
- Publicação (Deploy) de aplicações Web.

Esses conhecimentos serão utilizados durante todo o semestre para o gerenciamento dos projetos.

---

# Introdução ao JavaScript (Vanilla JS)

Foi apresentado o conceito de JavaScript como linguagem de script interpretada essencial para o desenvolvimento Front-end.

Também foi introduzido o conceito de **Vanilla JavaScript**, que consiste na utilização do JavaScript puro, sem bibliotecas ou frameworks externos.

Sua importância está na possibilidade de:

- Manipular páginas Web;
- Implementar lógica da interface;
- Comunicar aplicações com servidores.

---

# Introdução aos Frameworks Front-end

Durante o semestre serão estudados os principais conceitos relacionados aos Frameworks Front-end, incluindo:

- Conceito e importância;
- Benefícios para o desenvolvimento Web;
- Introdução aos Frameworks React, Vue e Angular;
- Arquitetura baseada em componentes;
- Reutilização de código;
- Gerenciamento de estado;
- Rotas;
- Integração com APIs.

# Critérios de Avaliação

A avaliação da disciplina será composta por:

- **55% — Avaliação Docente**
  - 20% Desenvolvimento do Projeto;
  - 20% Apresentação do Projeto;
  - 15% Atividades.

- **35% — Projeto Integrador**

- **10% — Autoavaliação**

O projeto será documentado como um **mini TCC**, contendo todas as etapas do desenvolvimento, planejamento, execução, resultados, desafios, soluções e análise crítica.

A apresentação também avaliará aspectos como:

- Organização do backlog;
- Desenvolvimento das páginas;
- Benchmarking;
- Implementação das funcionalidades.

---

# Importância do Portfólio

Foi destacado que manter um portfólio de projetos permite:

- Demonstrar habilidades práticas;
- Evidenciar o aprendizado adquirido;
- Facilitar avaliações;
- Aumentar oportunidades de estágio e emprego;
- Desenvolver organização e melhoria contínua.

---

# Atividades da Aula

Foram propostas duas atividades:

1. Desenvolver um projeto em **Vanilla JavaScript**, utilizando HTML, CSS e JavaScript, conectando o projeto ao GitHub e realizando o deploy utilizando a Vercel.

2. Formar grupos de 3 a 5 integrantes, criar um repositório no GitHub para armazenar as atividades da disciplina e elaborar um resumo da Aula 01 em Markdown. Além disso, escolher um Framework Front-end e produzir um relatório técnico em PDF apresentando suas características, vantagens, aplicações e um exemplo de uso.

---

# Conclusão

A Aula 01 apresentou a estrutura da disciplina, seus objetivos, metodologia, critérios de avaliação e conteúdos que serão estudados durante o semestre.

Também contextualizou a importância do desenvolvimento Front-end e dos Frameworks modernos no mercado de trabalho, preparando os alunos para o desenvolvimento de aplicações Web utilizando boas práticas, versionamento, deploy e arquitetura baseada em componentes.
