# 📚 Frontend Knowledge Base

Repositório dedicado à organização de todo o conteúdo da disciplina **Frameworks Front-end**.

Este repositório funciona como uma **base de conhecimento central** da matéria, reunindo resumos das aulas, atividades, anotações, materiais de apoio e projetos desenvolvidos ao longo do semestre.

O objetivo é manter todo o aprendizado organizado em um único local, facilitando consultas, revisões para avaliações e acompanhamento da evolução da disciplina.

---

# 🎯 Objetivos

* Organizar os resumos de cada aula;
* Registrar conceitos importantes;
* Armazenar atividades desenvolvidas durante a disciplina;
* Centralizar anotações e observações das aulas;
* Disponibilizar materiais de apoio e referências;
* Documentar projetos realizados ao longo do semestre;
* Construir uma base de conhecimento para futuras consultas.

---

# 📂 Estrutura do Repositório

```text
frontend-knowledge-base/
│
├── README.md
│
├── Plano de Ensino.pdf
│
├── aulas/
│   ├── aula-01/
│   │   ├── resumo.md
│   │   ├── anotacoes.md
│   │   └── atividades/
│   │
│   ├── aula-02/
│   ├── aula-03/
│   └── ...
│
└── projetos/

```

Cada pasta de aula poderá conter:

* **Resumo da aula**
* **Anotações pessoais**
* **Atividades**
* **Arquivos utilizados durante a aula**
* **Links e referências**

# 📌 Organização

Cada aula será documentada contendo, sempre que possível:

* Resumo dos principais conceitos;
* Anotações complementares;
* Atividades propostas;
* Exercícios desenvolvidos;
* Materiais utilizados pelo professor;
* Referências para estudo.

Dessa forma, o repositório se torna uma fonte organizada de consulta durante a disciplina e após sua conclusão.
