# 📚 Frontend Knowledge Base

Repositório dedicado ao armazenamento dos meus resumos, anotações e materiais de estudo da disciplina de **Frameworks Front-end** da faculdade.

O objetivo deste repositório é organizar o conteúdo aprendido durante as aulas, registrar conceitos importantes e servir como uma base de consulta para revisões futuras e desenvolvimento de projetos.

## 🎯 Objetivos

* Organizar os resumos de cada aula;
* Consolidar conceitos de Front-end;
* Registrar exemplos e boas práticas;
* Facilitar revisões para provas e projetos;
* Construir uma base de conhecimento pessoal.

## 📂 Estrutura do Repositório

```text
frontend-knowledge-base/
├── README.md
├── aula-01/
│   └── resumo.md
├── aula-02/
│   └── resumo.md
├── aula-03/
│   └── resumo.md
└── ...
```

Cada pasta representa uma aula e contém o resumo correspondente em Markdown.
